同人ラボ

プライバシーポリシー

Chrome 拡張機能「同人ラボ」が扱う情報について説明します。

送信する情報

拡張機能は、次の 2 つの場面で作品の ID (例: RJ01234567) を価格履歴のサーバーへ送ります。

  • 対応している作品ページを開いたとき。その作品の ID を送ります。作品 ID はページの URL から読み取ります。
  • 6 時間ごとの価格確認のとき。通知価格を設定した作品の ID を 1 件ずつ送ります。

送信の目的は、価格履歴を受け取ってグラフを描くことと、現在の価格を通知価格と比べることです。

送信先は doujin-labo.net の API サーバーです。通信は HTTPS で暗号化します。

送信しない情報

  • 設定した通知価格
  • 氏名、メールアドレス、ストアのアカウント情報
  • Cookie、ログイン状態、購入履歴
  • 対応ページ以外の閲覧履歴
  • ページの本文や入力した内容

利用者や端末を見分けるための ID は発行しません。

端末に保存する情報

通知価格を設定すると、拡張機能は次の情報をブラウザの拡張機能用の保存領域に保存します。

  • 作品の ID と作品名
  • 設定した通知価格
  • 最後に確認した価格と確認した時刻

価格確認のために送る作品の ID を除いて、これらの情報は端末の外へ送りません。通知を解除するか、拡張機能を削除すると消えます。

サーバーに残る記録

サーバーは、通常のウェブサイトと同じようにアクセスログを記録します。ログには、IP アドレス、ブラウザの種類、アクセス日時、要求された作品 ID が含まれます。アクセスログは障害の調査と不正な利用の防止に使います。

第三者への提供

上記の情報を第三者へ販売したり提供したりしません。広告やアクセス解析のための外部サービスも使っていません。

権限について

  • DLsite と FANZA 同人の作品ページでの動作: ページ内にグラフと通知価格の欄を差し込むために使います。
  • doujin-labo.net の価格履歴 API への通信: 価格履歴を受け取るために使います。
  • storage: 通知価格の一覧を端末に保存するために使います。
  • alarms: 6 時間ごとに価格を確認するために使います。
  • notifications: 通知価格以下になったことを知らせるために使います。

同人ラボ

プライバシーポリシー

Chrome 拡張機能「同人ラボ」が扱う情報について説明します。扱う情報は、グラフを見るだけの場合と、値下げ通知を使う場合で変わります。

グラフを見るだけの場合

対応している作品ページを開いたとき、拡張機能はその作品の ID (例: RJ01234567) をサーバーへ送ります。作品 ID はページの URL から読み取ります。送信の目的は、価格と販売数の履歴を受け取ってグラフを描くことです。

この場合、利用者や端末を見分けるための ID は発行しません。端末にも情報を保存しません。

値下げ通知を使う場合

通知価格を設定すると、拡張機能は次の情報をサーバーに登録します。

  • 端末 ID: 初めて通知価格を設定したときに、サーバーが無作為に発行します。同じ利用者の設定をまとめるために使います。
  • 通知価格を設定した作品の ID、通知価格、設定したときの価格
  • メールアドレス: 通知先として登録した場合

登録の目的は、設定した価格以下になったことをメールで知らせることです。メールアドレスは、確認メールのリンクを押して登録を完了した場合にだけ、通知に使います。

端末 ID は、ブラウザの拡張機能用の保存領域にも保存します。端末に保存するのは端末 ID だけです。

通知メールについて

  • 価格の確認は 1 日 1 回です。通知価格以下になった作品があるときにだけ、メールを送ります。
  • メールには、作品の名前、サムネイル画像、価格、ストアの作品ページへのリンクが入ります。成人向け作品の名前と画像が入ることがあります。
  • 作品へのリンクは doujin-labo.net を経由してストアへ移動します。リンクにはアフィリエイトリンクを含みます。
  • すべてのメールに、配信を止めるためのリンクが入ります。
  • 確認済みのメールアドレスを別の端末が登録したときは、引き継ぎの確認メールを送ります。メール内のリンクを押した端末だけが、前の通知設定を使えるようになります。リンクを押さなければ何も変わりません。
  • メールの送信には、メール配信事業者のサービスを使います。送信のために、宛先のメールアドレスとメールの本文を事業者へ渡します。

送信しない情報

  • 氏名、パスワード、ストアのアカウント情報
  • Cookie、ログイン状態、購入履歴
  • 対応ページ以外の閲覧履歴
  • ページの本文や、通知価格とメールアドレス以外に入力した内容

情報の削除

  • 通知価格は、作品ページのグラフの下にある「解除」で削除できます。
  • メールアドレスは、拡張機能のアイコンを押して出る画面の「メールアドレスを削除する」か、通知メール内の「配信を止める」で削除できます。
  • 拡張機能を削除すると、端末に保存した端末 ID は消えます。サーバーに残った登録の削除を希望する場合は、下のお問い合わせ先へ連絡してください。入れ直したあとに同じメールアドレスを登録すると、前の設定を引き継げます。

サーバーに残る記録

サーバーは、通常のウェブサイトと同じようにアクセスログを記録します。ログには、IP アドレス、ブラウザの種類、アクセス日時、要求された作品 ID が含まれます。アクセスログは障害の調査と不正な利用の防止に使います。

第三者への提供

上記の情報を第三者へ販売しません。メール送信の委託を除いて、第三者へ提供もしません。広告やアクセス解析のための外部サービスは使っていません。

送信先と権限

送信先は doujin-labo.net の API サーバーです。通信は HTTPS で暗号化します。

  • DLsite と FANZA 同人の作品ページでの動作: ページ内にグラフと通知価格の欄を差し込むために使います。
  • doujin-labo.net の API への通信: 価格と販売数の履歴を受け取り、通知価格とメールアドレスを登録するために使います。
  • storage: 端末 ID を端末に保存するために使います。

同人ラボ

プライバシーポリシー

Chrome 拡張機能「同人ラボ」が扱う情報について説明します。

送信する情報

対応している作品ページを開いたとき、拡張機能はその作品の ID (例: RJ01234567) をサーバーへ送ります。作品 ID はページの URL から読み取ります。送信の目的は、価格と販売数の履歴を受け取ってグラフを描くことです。

利用者や端末を見分けるための ID は発行しません。端末にも情報を保存しません。

送信しない情報

  • 氏名、メールアドレス、パスワード、ストアのアカウント情報
  • Cookie、ログイン状態、購入履歴
  • 対応ページ以外の閲覧履歴
  • ページの本文や、ページに入力した内容

サーバーに残る記録

サーバーは、通常のウェブサイトと同じようにアクセスログを記録します。ログには、IP アドレス、ブラウザの種類、アクセス日時、要求された作品 ID が含まれます。アクセスログは障害の調査と不正な利用の防止に使います。

第三者への提供

上記の情報を第三者へ販売しません。第三者へ提供もしません。広告やアクセス解析のための外部サービスは使っていません。

送信先と権限

送信先は doujin-labo.net の API サーバーです。通信は HTTPS で暗号化します。

  • DLsite と FANZA 同人の作品ページでの動作: ページ内にグラフを差し込むために使います。
  • doujin-labo.net の API への通信: 価格と販売数の履歴を受け取るために使います。

外部へのリンク

拡張機能のアイコンを押して出る画面に、公式 X アカウント (@doujinlabonet) へのリンクがあります。リンクを押すと x.com を開きます。押さなければ、x.com へ何も送りません。

変更

扱う情報が変わるときは、このページを更新します。

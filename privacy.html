同人作品の価格推移グラフ

プライバシーポリシー

Chrome 拡張機能「同人作品の価格推移グラフ (doujin-labo)」が扱う情報について説明します。

送信する情報

対応している作品ページを開いたとき、拡張機能はその作品の ID (例: RJ01234567) を価格履歴のサーバーへ送ります。作品 ID はページの URL から読み取ります。送信の目的は、その作品の価格履歴を受け取ってグラフを描くことです。

送信先は doujin-labo.net の API サーバーです。通信は HTTPS で暗号化します。

送信しない情報

  • 氏名、メールアドレス、ストアのアカウント情報
  • Cookie、ログイン状態、購入履歴
  • 対応ページ以外の閲覧履歴
  • ページの本文や入力した内容

利用者や端末を見分けるための ID は発行しません。

サーバーに残る記録

サーバーは、通常のウェブサイトと同じようにアクセスログを記録します。ログには、IP アドレス、ブラウザの種類、アクセス日時、要求された作品 ID が含まれます。アクセスログは障害の調査と不正な利用の防止に使います。

端末に保存する情報

拡張機能は端末に情報を保存しません。

第三者への提供

上記の情報を第三者へ販売したり提供したりしません。広告やアクセス解析のための外部サービスも使っていません。

権限について

  • DLsite と FANZA 同人の作品ページでの動作: ページ内にグラフを差し込むために使います。
  • doujin-labo.net の価格履歴 API への通信: 価格履歴を受け取るために使います。

変更

扱う情報が変わるときは、このページを更新します。
